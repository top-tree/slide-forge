% pages-examples/cite.tex   —— 配置⑤：论文 / 作品条目（可带超链接）
%
% 用于：论文、项目、作品清单。一条 = 两行，两行之间比 \DeckLine 更紧（0.12cm），
% 让它们读作一条完整记录；条目之间 0.34cm 拉开。
%
% 用法要点：
%   - \DeckCite{标题行}{说明行}
%   - 想做成可点击的链接，用 \DeckLink{URL}{链接文字} 嵌在标题行里：
%         \DeckCite{\DeckLink{https://...}{CVPR 2026}　第三作者}
%                  {IEEE/CVF Conference on Computer Vision and Pattern Recognition}
%     链接文字取简短标识（会议名 + 年份）即可，不要把整段长标题做成链接
%     ——那会让整行变成强调色，既杂乱又难读。
%   - 只放标题行、说明行留空时，直接改用 \DeckLine 更省事。
%   - \DeckLink 的颜色是强调色、无下边框（hyperref 默认的方框很难看，已关掉）。
%   - 长 URL 不需要断行处理，\href 不影响排版宽度。
%
% 验证链接是否真的可点（只编译通过不代表链接生效）：
%     pdftohtml -xml -f <页码> -l <页码> main.pdf out.xml
%   然后在 out.xml 里搜 <a href= 确认。
