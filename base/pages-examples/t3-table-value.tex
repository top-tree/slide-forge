% pages-examples/table-value.tex   —— 配置③：「名称 — 数值」对照表
%
% 用于：成绩单、指标表、参数表——左边是名称，右边是数值。
%
% 用法要点：
%   - 用 \DeckCourseTable{表体}，表体每行写 `名称 & 数值 \\`。
%   - 表头用 \DeckCourseHead{左列名}{右列名}，紧跟 \DeckCourseRule 画细线。
%   - 列宽分配：左列占满剩余宽度、右列数值右对齐。所以适合"长名称 + 短数值"。
%   - 如果内容是"短标签 + 长文字"（比如年份 + 一段描述），
%     不要用这个，改用 table-list.tex 的 \DeckListTable，否则长文字会被右对齐得零碎。
%   - 表宽自动等于正文宽，不需要手算列宽（手算容易差 0.03cm 而溢出）。
%   - 行距默认跟随正文；一页放不下时在该页开头覆盖：
%         \setlength{\DeckTableLeading}{15pt}
%     但**不要改字号**——字号只有两档，不允许逐页调。
%
% 容量：数值表最多 5 行数据 + 表头。

\DeckCourseTable{%
  \DeckCourseHead{名称}{数值}
  \DeckCourseRule
  第一项 & 100 \\
  第二项 & 95 \\
  第三项 & 92 \\
}
