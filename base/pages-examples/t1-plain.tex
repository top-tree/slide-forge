% pages-examples/plain.tex   —— 配置①：纯文字陈述
%
% 用于：一段说明、几条并列的事实。这是最常用的配置。
%
% 用法要点：
%   - 每一行用 \DeckLine；它自带悬挂缩进（折行后与首行文字对齐），
%     以及 0.30cm 的行间距。
%   - 需要分组时插一个 \DeckGap（0.40cm）——这是唯一的分组手段，
%     不要用分隔线、小标题或色块。
%   - 一行控制在 30 个全角字符以内（西文数字约占半角），否则会折行。
%   - 一页最多 6 行。超过就拆页，不要挤。
%
% 层级表达：只有"加粗"和"留白"两种手段。整页字号完全一致。

\DeckGap

\DeckLine{每一条要点写成一行，行与行之间自动留出 0.30cm 间距。}
\DeckLine{想强调某个词时用 \textbf{加粗}，一句话里不要超过一处。}
\DeckLine{整页字号、字重、颜色完全一致，层级靠留白分组。}

\DeckGap

\DeckLine{这是第二组内容。上面那个空行就是分组手段，不需要小标题。}
