% pages-examples/figures.tex   —— 配置⑥：两图并排
%
% 用于：一页只放两张图，不放文字（或只放很少文字）。
%
% 用法要点：
%   - \DeckFigures{左图}{右图}{左图高度}{右图宽度}
%   - 为什么要给两个不同的参数？因为 \includegraphics 的 width/height
%     是"缩放后"尺寸：只给 height 时，宽度按原图比例推算。两张图比例不同
%     又都想等高，就必须给其中一张显式 width。
%   - 算出等高的办法：设目标高 H，则
%         左图 width = H × (左图宽/左图高)
%         右图高     = 右图 width ÷ (右图宽/右图高)
%   - 关键约束：**两图宽度之和必须明显小于正文宽（14.25cm）**。
%     只差 0.03cm 都会让第二张图被挤到下一行，并报 overfull vbox
%     （报的是竖直溢出，看不出是宽度问题，很难查）。留 0.3cm 以上余量。
%   - 不要用 beamer 的 columns：它的栏间距会与给定宽度叠加，算不准；
%     \DeckFigures 内部用 \hfill 撑开，宽度完全可控。
%   - 图片先用外部工具缩放到长边约 2400px 再入稿，否则 PDF 会异常臃肿。
%     手机拍的竖图通常还要旋转与裁边（裁掉键盘、桌面等入镜杂物）。

\DeckFigures{figures/left.jpg}{figures/right.jpg}{5.10cm}{7.05cm}
