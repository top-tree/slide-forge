% pages-examples/table-list.tex   —— 配置④：「短标签 — 长文字」表
%
% 用于：年份 + 奖项描述、日期 + 事件这类内容。
%
% 用法要点：
%   - 用 \DeckListTable{表体}，表体每行写 `标签 & 文字 \\`。
%   - 表头用 \DeckListHead{左列名}{右列名}，紧跟 \DeckCourseRule。
%   - 与 \DeckCourseTable 的唯一区别是列宽分配方向：
%       数值表：名称占满 + 数值右对齐（适合"长名称 + 短数值"）
%       本  表：标签窄左 + 文字占满左对齐（适合"短标签 + 长文字"）
%     选错了会让长文字被右对齐得零碎，甚至溢出列宽。
%   - 左列宽度由内容自动决定，不要手写 \makebox 去撑。
%   - 长文字行控制在 30 个全角字符以内，否则折行后悬挂缩进只对齐首行，
%     第二条折行行会显得散。
%
% 容量：本表最多 8 行数据 + 表头。

\DeckListTable{%
  \DeckListHead{标签}{文字}
  \DeckCourseRule
  2026 & 第一条较长的描述文字写在这里，它会占满右侧并自动折行。 \\
  2025 & 第二条。 \\
  2024 & 第三条。 \\
}
